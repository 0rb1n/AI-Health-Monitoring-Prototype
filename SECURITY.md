# Security Policy

## Reporting a Vulnerability

Please do **not** open public issues for security vulnerabilities.

Instead, report privately by opening a GitHub Security Advisory (preferred) or by contacting repository maintainers with:

- Affected component/file
- Reproduction steps
- Impact assessment
- Suggested mitigation (if known)

We will acknowledge reports as quickly as possible and work on remediation.

## Scope

This repository is a prototype and should not be used for production medical decisions. Security reports are still welcomed for all code, workflows, and dependencies.

## Data Safety Guidelines

- Never commit API keys, credentials, or tokens.
- Never commit sensitive personal or medical data.
- Use synthetic/sample data only for tests and demos.
