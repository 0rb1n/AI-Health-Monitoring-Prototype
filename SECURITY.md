# Security Policy

## Supported Versions
This repository is a prototype. Security updates are applied on a best-effort basis to the latest default branch state.

## Reporting a Vulnerability
Please do **not** open public issues for security vulnerabilities.

Instead, report privately using one of these methods:
- GitHub Security Advisories (preferred)
- Direct maintainer contact through repository security contact channels

Include:
- Description of the vulnerability
- Reproduction steps
- Potential impact
- Suggested remediation (if available)

## Response Expectations
Maintainers will:
1. Acknowledge receipt as quickly as possible.
2. Assess impact and prioritize remediation.
3. Coordinate disclosure timing with the reporter.

## Disclosure
We follow responsible disclosure. Public details should be shared only after a fix or mitigation is available.
